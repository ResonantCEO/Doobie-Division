---
name: Storefront heading visibility
description: Semantics of the per-category storefront heading choice
---

The category heading visibility choice controls only the title above that category's storefront product section. Category navigation labels, organizer labels, products, and assigned advertisements must remain visible.

**Why:** A category-specific banner ad can already supply the visual title, so repeating the section heading is redundant; customers still need the category in navigation.

**How to apply:** Keep section-heading rendering separate from category availability and navigation when editing storefront category UI.
